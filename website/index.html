macOS · Apple Silicon

Available

Install the preview with Homebrew, then open the guided setup. 

brew install --cask kapital-labs/tap/kitrove-rc
kitrove init

Requires Homebrew. The cask currently supports Apple Silicon Macs only.

Already installed the preview? 
brew update
brew upgrade --cask kapital-labs/tap/kitrove-rc
kitrove configure

Homebrew updates the binary. Your collection and setup are separate.

Know what moves

Portable doesn't mean
identical everywhere.

Agent tools have different capabilities. Kitrove preserves native details and reports transfer fidelity so you can decide what to apply.

Credentials, accounts, trust decisions, and machine-specific paths stay outside collection sync. You still install and authorize each agent tool on each computer.

Before you start

A few useful answers.

Does init create a folder?

Yes, after you confirm the plan. The walkthrough suggests ~/Kitrove for your collection and shows a separate machine-local state location. You can choose another collection location.

Does Kitrove sync in the background?

No. You start a sync operation and review the plan. Full sync can publish local additions as well as bring remote changes back.

Will it replace my existing skills?

Adoption leaves source files in place. Applying is a separate confirmation. Kitrove refuses unmanaged destination conflicts rather than overwriting them.

Is this a stable release?

No. RC4.2 is a prerelease. A bounded skill round trip between an existing Apple Silicon Mac and Ubuntu passed using a filesystem snapshot backend transferred between steps. That does not establish clean-Mac online/offline first launch, all capability types, live agent-tool execution, or concurrent sync.
