# Grok Bot pilot sample

This directory contains an inert text skill for a disposable Kitrove collection.
It contains no scripts, native install directives, credentials or provider setup.

The [pilot](../../docs/integrations/grokbot/README.md) uses a copy under a synthetic
Claude source root, collects it, and creates an authored `starter-review` pack.
The subsequent inspection and planning commands make no placement or sync changes.
Do not point the demo at a personal collection or modify native tool folders to
reproduce it. The sample does not install or create a Grok Bot.
