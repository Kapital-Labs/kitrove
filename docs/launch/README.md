# Launch preparation

Reviewed November 18, 2026. This packet prepares an evaluation-preview announcement;
it does not authorize publishing, scheduling, account connections or a stable launch.

Start with [product positioning](../PRODUCT-POSITIONING.md), then use:

- [Claims ledger](CLAIMS.md): current release facts, evidence and exclusions.
- [Blog outline and announcement brief](BRIEF.md): audience, evidence, strongest
  objection, named acknowledgments and publication decisions.
- [Exploratory blog](BLOG-DRAFT.md) and [LinkedIn draft](LINKEDIN-DRAFT.md): material
  for Brandon's review, not approved copy.
- [Landscape review](../research/2026-11-18-landscape.md): pinned primary sources;
  avoid stale comparisons or claims that a feature is unique.
- [Product priorities](../PRODUCT-PRIORITIES.md): preview usability and stable
  acceptance gaps before adding more integrations.

Before publication, Brandon approves the premise and wording. The maintainer
checks the release/tap/site status, source ledger and the demo instructions again.
Replace any future blog-link placeholder with its approved destination. Review
the exact post on the target platform; drafting and passing checks are not
publication approval. No social or blog platform has been changed by this packet.
